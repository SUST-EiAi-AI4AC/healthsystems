【软著名】：基于多模态AI的心理健康管理APP
【版本号】：V2.0.0
【软件分类】：应用软件
【开发硬件环境】：Intel Core i7 
【运行的硬件环境】：移动端：Android 8.0 及以上、iOS 12.0 及以上智能手机
【开发该软件的操作系统】：Windows 10/11 操作系统
【软件开发环境/开发工具】：HBuilderX, IntelliJ IDEA, PyCharm, Navicat for MySQL, Git
【该软件的运行平台/操作系统】：Android, H5 移动端浏览器, Web 浏览器 , Windows/Linux 服务器
【软件运行支撑环境/支持软件】：JDK 1.8+, Python 3.10+, MySQL 8.0, Nginx 1.20+, Android SDK, JPush SDK
【编程语言】：JavaScript (Vue/uni-app), HTML/CSS
【源程序量】：48560 行
【开发目的】：
	基于 uni-app 跨平台前端技术，集成 Garmin 智能手环客观生理数据同步、HTP房树人 Canvas 智能绘图投射心理评测、10余种专业心理自评量表、EMA 生态瞬时情绪状态评估、AI 陪伴对话审计、情绪日记追踪、音视频半结构化访谈录制，以及专业的医生端管理后台，建立起客观生理和主观心理的“多模态精神健康评估数学模型”，旨在为用户和医护人员提供“监测-评估-疗愈-追踪-干预”的数字精神健康管理闭环，提升精神亚健康防治的信息化水平。
【面向领域行业】：数字医疗、心理健康、移动健康管理
【功能特点】：
	1. 医患绑定与协同：医生端生成 6 位邀请码，患者注册时完成绑定，保障临床数据隐私。
	2. Garmin 生理数据同步：拉取手环客观生理指标（心率、步数、睡眠分期、血氧 SpO2、压力指数、身体能量），并进行 ECharts 历史趋势展示。
	3. HTP 房树人投射测验：提供多点触控 Canvas 画白板，支持手画绘图与 AI 视觉模型投射心理评估，自动输出色彩、构图等 6 维度智能报告。
	4. 专业心理量表测评：内置 SCL-90、PSQI、大五人格等 10 余种专业量表自测，医生后台提供风险等级彩色徽章一键过滤及前后对比趋势图。
	5. EMA 与情绪日记追踪：PAM-16 情绪图谱采集瞬时心境，NLP 模型提取日记主情绪并计算心情得分，支持“私密/公开”隔离策略。
	6. 疗愈空间与 AI 陪伴：提供 24h 在线“心晴”AI 心理陪伴流式对话，并提供引导式冥想音频与 Web 减压解压小游戏。
	7. 音视频模拟访谈录制：支持 WebRTC 摄像头与麦克风录制 12 道半结构化访谈情境，支持视频文件打包安全上传与后台流畅播放。
	8. 多模态雷达图与推送：ECharts 融合主客观数据生成多维雷达图，支持一键 PDF 报表导出；集成极光推送进行每日催填与定时提醒调度。
【技术特点】：
	1. 跨平台多端开发：基于 uni-app + Vue.js 实现移动端核心界面，实现 Android、iOS 和 H5 平台的高效率编译和界面高保真还原。
	2. 多语言异构协同调度：采用 Spring Boot 后端驱动，通过守护进程异步执行多线程 Python 代理拉取海外 Garmin Cloud API，完成数据去重与清洗入库。
	3. 多模态 AI 大模型驱动：深度集成大语言模型流式输出与视觉多模态处理技术，解决 HTP 画卷图像投射特征识别与对话情感极性分析的临床瓶颈。
	4. Shiro + JWT 双重网关控制：采用 Apache Shiro 权限体系配合 JWT（JSON Web Token）实现无状态身份鉴权，保证接口传输的安全性。
	5. 临床数据隐私与安全加密：数据库核心生理数据、佳明手环授权凭证采用对称加密存储，敏感聊天日志在后台提供高安全性会话审计。
	6. 精细化定时任务调度：利用 Spring 整合极光推送 SDK，基于 `user_id` 别名实现精准推送，配置每日 21 点/23 点自动催填策略及重发机制。
